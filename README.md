# Thread Network Tool

A local app for understanding Thread networks and joining compatible border routers to a chosen existing network.

Status: initial build, not a release. No network mutation is currently implemented.

The first release does not depend on automatic transfer of existing accessories. Read-only discovery and explicit compatibility evidence come first. Home Assistant and AI are optional.

See [build scope](docs/BUILD-SCOPE.md), [engine contract](docs/ENGINE-CONTRACT.md), and [progress](PROGRESS.md).
