# v0.1.0-alpha.1 — developer alpha

Thread Network Tool is an experimental local application for understanding Thread networks. Contributions and focused testing help are welcome; start with [Contributing](../../CONTRIBUTING.md) and the [developer preview](../CONTRIBUTOR-PREVIEW.md). This is not a general household migration pilot.

Default packages are read-only. A separately enabled Mac alpha includes a real worker for joining an **entire empty source network** to a selected existing network. It requires complete credentials for both networks, independent source inventory and confirmation, and does not migrate accessories or automatically roll back. Discovery cannot prove that a network is empty. No retail Eero model and firmware combination has been verified for the packaged join or recovery flow. Do not use a working household as a test network. See [Mac alpha](../MAC-ALPHA.md) and the [tester quickstart](../MAC-ALPHA-TESTER.md).

- The local ad hoc signed Mac zip documented in the [acceptance record](../MAC-ALPHA-ACCEPTANCE.md) was built from production source `7422ddc8a3b14dec75acb2a005c59198b39d3bc9`. It is not Developer ID signed or notarized; clean-Mac installation and physical Intel execution remain unverified. The record identifies its local path, hashes and limits. Associate any distributed binary with its exact source commit and artifact hashes; do not treat this record as proof for a different build.
- The pinned isolated OpenThread simulator repair passed the unchanged full app fixture in **375.3 seconds**, across **two real Flutter test processes**, with all **seven original gates**, including independent IP connectivity. This evidence is for the pinned software fixture and does not establish retail Eero or packaged Mac compatibility. See [the simulator record](../SIMULATOR-COUNTER-FIX.md).
- Apple credential retrieval on Mac, phone companions, Windows networking and accessory migration remain outside the bounded Mac alpha. Help with installation, credential provisioning, platform networking and controlled spare-Eero testing is welcome.

`SHA256SUMS.txt`, and automatically generated source archives. The ZIP retains
